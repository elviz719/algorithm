# Панцер-Архив

Браузерная игра-досье о всех проектах немецкой бронетехники 1933–1945 годов.

Игрок «рассекречивает» карточки танков и самоходных установок — от лёгкого
Pz.Kpfw. I до нереализованных сверхтяжёлых проектов вроде «Ratte» — отвечая
на вопрос по каждой машине. За правильный ответ начисляются очки, прогресс
сохраняется локально в браузере.

Игра охватывает 34 машины/проекта по 7 категориям: лёгкие, средние и тяжёлые
серийные танки, сверхтяжёлые и нереализованные проекты, стандартизированная
серия «Е», истребители танков, штурмовые и самоходные орудия.

## Запуск

Откройте `game/panzer-archiv.html` в любом современном браузере — игра
работает полностью локально, без сборки и серверной части.
