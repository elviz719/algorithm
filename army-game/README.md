# Танковая Армия СССР

Браузерная аркадная игра о советской бронетехнике Второй мировой войны (1939–1945).
Один самодостаточный HTML-файл — без сборки, без внешних JS/CSS зависимостей
(кроме шрифтов Google Fonts).

## Как запустить

Открыть `index.html` в любом браузере (двойной клик), либо поднять локальный
сервер из этой папки:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Режимы

- **В бой** — выбираете одну из 19 играбельных советских машин (Т-26, БТ-7,
  Т-60, Т-70, Т-34, Т-34-85, КВ-1, ИС-2, ИС-3, СУ-76, СУ-85, СУ-100, СУ-152,
  ИСУ-152, БА-64, ХТ-26, ОТ-34, ЗИС-30, Т-44) и отражаете волны наступающей
  немецкой бронетехники на top-down поле боя. Управление: **WASD**/стрелки —
  движение, **мышь** — прицеливание, **ЛКМ** — огонь.
- **Энциклопедия бронетехники** — «Вся бронетехника СССР во Второй мировой
  войне»: 45 образцов техники (лёгкие, средние и тяжёлые танки, танкетки,
  плавающие и огнемётные танки, САУ, бронеавтомобили, бронетягач и опытные
  тяжёлые прототипы СМК/Т-100) с историческими характеристиками — масса,
  бронирование, вооружение, скорость, экипаж, количество выпущенных машин,
  краткое описание и настоящий боковой силуэт машины в стиле армейских
  карточек распознавания техники (катки с ободом и ступицей, антенны, люки,
  топливные баки и т.д.).

## Структура

Вся игра — в `index.html`:
- `<style>` в начале файла — оформление (тема «оперативная сводка/приборная
  панель», шрифты Oswald + PT Sans + PT Mono);
- первый `<script>` — `VEHICLE_DATABASE` (база машин) и `SILHOUETTES` (SVG-силуэты
  по семействам шасси);
- второй `<script>` — движок боя на `<canvas>`;
- третий `<script>` — переключение экранов и рендер энциклопедии/списка выбора.

Добавить новую машину — значит добавить один объект в `VEHICLE_DATABASE` и,
при желании, пометить его `playable: true`, чтобы он появился в списке выбора
для боя, а также указать существующий или новый ключ `sil` из `SILHOUETTES`.
