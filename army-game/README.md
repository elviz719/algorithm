# Танковая Армия СССР

Браузерная аркадная игра о советской бронетехнике Второй мировой войны (1939–1945).
Чистый HTML/CSS/JavaScript, без сборки и внешних зависимостей.

## Как запустить

Открыть `index.html` в браузере, либо поднять локальный сервер из этой папки:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Режимы

- **В бой** — выбираете одну из играбельных советских машин (Т-26, БТ-7, Т-34,
  Т-34-85, КВ-1, ИС-2, ИС-3, СУ-76, СУ-85, СУ-100, СУ-152, ИСУ-152, Т-60, Т-70,
  БА-64) и отражаете волны наступающей немецкой бронетехники на top-down поле боя.
  Управление: **WASD**/стрелки — движение, **мышь** — прицеливание, **ЛКМ** — огонь.
- **Энциклопедия бронетехники** — «Вся бронетехника СССР во Второй мировой войне»:
  32 образца техники (лёгкие, средние и тяжёлые танки, САУ, бронеавтомобили)
  с историческими характеристиками — масса, бронирование, вооружение, скорость,
  экипаж, количество выпущенных машин и краткое описание.

## Структура проекта

```
army-game/
├── index.html          — разметка экранов (меню, выбор техники, бой, энциклопедия)
├── css/style.css       — оформление
└── js/
    ├── data.js         — база данных бронетехники СССР (VEHICLE_DATABASE)
    ├── game.js         — движок боя на <canvas> (движение, стрельба, волны врагов)
    └── ui.js           — переключение экранов, рендер списков энциклопедии и выбора техники
```

Добавить новую машину — значит добавить один объект в массив `VEHICLE_DATABASE`
в `js/data.js` и, при желании, пометить её `playable: true`, чтобы она появилась
в списке выбора для боя.
